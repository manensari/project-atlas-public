# Code of Conduct

## Our Commitment

Project Atlas is committed to maintaining a welcoming, respectful, and collaborative environment for everyone.

We encourage constructive discussions, thoughtful feedback, and professional collaboration regardless of experience level, background, or expertise.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Provide constructive feedback.
- Help improve discussions and documentation.
- Respect differing technical opinions.
- Focus on solving problems rather than criticizing people.
- Report security issues responsibly.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks.
- Discrimination of any kind.
- Spam or malicious content.
- Intentionally disruptive behavior.
- Knowingly submitting malicious code.
- Sharing confidential or private information without permission.

## Project Governance

Project Atlas follows a maintainer-reviewed development model.

The repository owner and authorized maintainers are responsible for reviewing and accepting contributions into the official project.

Community discussion is encouraged, but final decisions regarding project direction and code acceptance rest with the maintainers.

## Enforcement

Project maintainers may edit, reject, lock, or remove contributions, issues, discussions, or comments that violate this Code of Conduct.

Repeated or serious violations may result in restricted participation.

## Contact

If you experience or witness behavior that violates this Code of Conduct, please open a private discussion or contact the project maintainers.

Thank you for helping make Project Atlas a productive and respectful project.
