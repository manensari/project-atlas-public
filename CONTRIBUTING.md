# Contributing to Project Atlas

Thank you for your interest in contributing to Project Atlas.

Project Atlas is a public research and development project focused on building a secure, privacy-first desktop file management system. Community contributions are welcome and appreciated.

## Contribution Process

1. Fork this repository.
2. Create a new branch for your work.
3. Make your changes and test them.
4. Commit your changes with clear commit messages.
5. Open a Pull Request describing:
   - What you changed.
   - Why the change is useful.
   - Any limitations or future improvements.

## Review Process

Every Pull Request is reviewed before becoming part of the official Project Atlas codebase.

A Pull Request may be:

- Accepted and merged.
- Accepted with requested modifications.
- Returned for revision.
- Closed if it does not align with the project's goals.

No contribution is merged automatically.

## Coding Guidelines

Please:

- Write clean, readable, and maintainable code.
- Keep commits focused on a single purpose.
- Document new features when appropriate.
- Avoid unnecessary dependencies.
- Respect user privacy and security in all implementations.

## Reporting Issues

Before opening a new issue:

- Search existing issues.
- Include clear reproduction steps.
- Provide logs or screenshots when helpful.

## Feature Requests

Feature requests are welcome.

When proposing a feature, explain:

- The problem it solves.
- Your proposed solution.
- Possible alternatives.
- Any potential trade-offs.

## Recognition

Every accepted contribution is permanently credited through GitHub's commit history.

Significant community contributions may also be recognized in the project's CONTRIBUTORS.md file and release notes.

## Code of Conduct

By participating in this project, you agree to follow the project's Code of Conduct.

Thank you for helping improve Project Atlas.
