# Security Policy

## Supported Versions

Project Atlas is currently under active development.

Security fixes will be applied to the latest development version.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not create a public GitHub Issue**.

Instead:

- Open a private GitHub Security Advisory (if enabled).
- Or contact the project maintainer privately.

Please include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any suggested mitigation.

Responsible disclosure is appreciated and helps keep Project Atlas secure for everyone.

---

## Scope

Security reports may include, but are not limited to:

- Authentication
- Encryption
- File handling
- Data privacy
- Permission management
- Local storage
- AI-assisted features
- Third-party dependencies

---

## Response

Every valid report will be reviewed.

Confirmed vulnerabilities will be investigated, fixed, and acknowledged in future release notes where appropriate.

Thank you for helping improve the security of Project Atlas.
